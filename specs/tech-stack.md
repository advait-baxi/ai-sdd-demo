# Tech Stack

## Core Framework
- **Next.js 14+ (App Router)**: Chosen for its reliability, industry popularity, and seamless integration of server-side logic and client-side interactivity.

## Language & Validation
- **TypeScript**: Strict type-safety for a reliable engineering foundation.
- **Zod**: Schema-first validation for all data entry and API boundaries.

## UI & Styling
- **Tailwind CSS**: Utility-first CSS for rapid, consistent styling.
- **shadcn/ui**: Accessible, high-quality component primitives for a professional dashboard.

## Data & Infrastructure
- **SQLite**: Relational database for structured health and booking records.
- **Prisma**: Type-safe ORM for reliable database interactions.
- **NextAuth.js (Auth.js)**: Standardized authentication and session management.
